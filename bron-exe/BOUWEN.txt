Lutrea-Profielviewer.exe opnieuw bouwen (na een wijziging in index.html/viewer.js)
1. Kopieer index.html, viewer.js, manifest.webmanifest, sw.js, merk-lutrea.png,
   icons\ en vendor\ naar een submap "app" naast main.go.
2. Met Go 1.22+ geïnstalleerd, in deze map:
     set GOOS=windows& set GOARCH=amd64& set CGO_ENABLED=0
     go build -trimpath -ldflags "-H windowsgui -s -w" -o Lutrea-Profielviewer.exe .
   (rsrc_windows_amd64.syso zorgt voor het icoon en de versie-info)
3. Tests (hebben ook de map "app" nodig):  go vet ./...  en  go test ./...
   toolsouw.ps1 doet dat vanzelf vóór het bouwen en stopt bij een fout.
